# Christensen _et al_., 2025

This is a GitHub related to the paper "A conserved differentiation program facilitates inhibitory neuron production in the developing mouse and human cerebellum" by Christensen _et al_., 2025. Scripts are available to recreate the analyses. The _in vivo_ mouse scRNA-seq data is available at ArrayExpress (Accession E-MTAB-13353). The targeted DamID sequencing data is available at NCBI’s Gene Expression Omnibus (GEO Series accession GSE292043). The _in vitro_ scRNA-seq data of primary mouse and human NEPs are available NCBI’s Gene Expression Omnibus (GEO Series accession GSE301654). Please direct any inquiries to jbc53@cam.ac.uk.
